# Hong Shing pilot — the owner conversation

*One page for Daniel to bring to the sit-down. Goal: leave with answers to the
two questions only the owner can answer, plus the operating boundaries. Every
question is multiple-choice with a proposed default, so the conversation takes
fifteen minutes, not an afternoon.*

---

## 1. What decisions do you want made for you?

Show the This Week screen, then ask: **"Which of these would you actually act
on — and what's missing?"**

| Decision the system makes today | Would you act on it? |
|---|---|
| "These regulars stopped coming — send them an offer" | ☐ yes ☐ no |
| "These first-timers never came back — invite them back" | ☐ yes ☐ no |
| "These rewards expire this week — remind the holders" | ☐ yes ☐ no |
| "Tuesdays are dead — aim your next promo there" | ☐ yes ☐ no |
| "This offer isn't landing / this one is — change or lean in" | ☐ yes ☐ no |
| "This QR placement isn't converting — move the card" | ☐ yes ☐ no |

**Then the open question:** what do you wish someone told you every week that
isn't on this list? (Candidates to probe: staffing levels vs. expected volume,
what to 86 or push tonight, purchasing quantities, menu price checks.)
*Whatever they name first is the next card we build.*

## 2. What number makes this pilot a success?

Proposed primary metric (say it, then let them react):

> **Captured phone numbers per 100 covers, over 30 days.**
> Keep going above ~30. Rework below ~50 captured total.

Secondary (the money proof): **win-back revenue attributed** — "we sent 12
offers, 4 people came back, $217 through the door." The ledger computes this
automatically; agree it's the number we review together monthly.

- Owner's own definition of success, in their words: ______________________

## 3. Operating boundaries (so the system never embarrasses them)

| Question | Default | Owner's answer |
|---|---|---|
| Standard offer for win-backs | 10% off next visit, 30 days | |
| Max discount ever issued without asking | 15% | |
| People who should NEVER get discounts | VIPs (the system already warns) | |
| Texting: OK to text opted-in customers? | Yes, CASL-gated, max 1/week each | |
| Consent capture at counter — will staff ask? | "Want texts when you have a reward?" | |
| Blackout dates (no promos) | Lunar New Year week, Valentine's | |
| Who holds the tablet, and when | Front counter, all open hours | |

## 4. Phone channel (Act 2 preview — set expectations, don't promise dates)

- Default when the AI can't handle a call: **it tells the caller to call the
  restaurant directly** — staff aren't expected to watch a screen during rush.
- When a call does escalate, the Front Desk tablet shows the caller's name,
  usual order, and any live reward before staff pick up.
- We capture every caller's number + context so nothing said on the phone is
  lost — ask: **"who reviews that, and when?"**
